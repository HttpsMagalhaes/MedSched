# MEDSCHED

O MEDSCHED é uma aplicação web desenvolvida para agendar e gerenciar consultas médicas online. O projeto propõe uma solução inovadora para resolver a problemática do agendamento manual, visando oferecer maior conforto, segurança e otimização de tempo para pacientes e instituições.

## 🚀 Tecnologias Utilizadas
*   **Frontend:** HTML, CSS, BOOTSTRAP e Javascript.
*   **Backend:** PHP.
*   **Banco de Dados:** MySQL.
*   **Metodologia e Modelagem:** Uso do framework SCRUM para gerenciamento e UML (Unified Modeling Language) para modelagem visual do sistema.

## ⚙️ Funcionalidades
*   Cadastro de pacientes, médicos e empresas no sistema.
*   Criação e modificação de perfis de usuário.
*   Sistema de busca flexível para encontrar médicos disponíveis por especialidade e cidade.
*   Agendamento de consultas médicas online de forma intuitiva.
*   Gerenciamento completo da agenda por parte dos médicos (visualização, alteração e cancelamento).

## 📌 Status do Projeto
O projeto consiste em um protótipo funcional que já desempenha suas funções cruciais de agendamento e gerenciamento.
